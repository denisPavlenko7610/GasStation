# GasStation

Симулятор заправки на Unity 6 + DOTS (Entities, Entities Graphics, Unity Physics, URP).
Целевая версия — **Unity 6.6**. Проект пока сохранён в 6000.0.23f1, см. раздел «Переход на Unity 6.6».

План развития: [docs/ROADMAP.md](docs/ROADMAP.md).

## Быстрый старт: готовый уровень

Выбери меню **GasStation → Построить уровень «Пустыня»**. Инструмент соберёт из пака ассетов
«Gas station» новую сцену `Assets/Scenes/Desert.unity` и откроет её:
- трасса с фонарями и отбойником, съезд на площадку;
- навес с четырьмя колонками (две старые закрыты до улучшения «Новая колонка»);
- магазин-операторская, цистерна, ржавый автомат, старая машина, указатель, знаки, конусы;
- дырявый забор, кактусы, кусты и песок вокруг;
- бокс шиномонтажа (горка колёс и конусы) справа спереди, мойка под вторым навесом справа от колонок, туалет (временный домик) и стоянка на 4 фуры за магазином;
- SubScene `Assets/Scenes/Desert/DesertGameplay.unity` со станцией, магазином (пешеход-водитель
  сохраняется в `Assets/Prefabs/Characters/Pedestrian.prefab`), мойкой, спавнером машин, колонками,
  игроком и **45 кусками мусора**: игра начинается на заброшенной заправке.

После сборки нажми Play. Уровень можно перестроить той же командой, а дальше двигать объекты руками.

## Как добавить геймплей в свою сцену

1. Открой сцену `Assets/Scenes/Day.unity`.
2. В иерархии включи галку у SubScene `Entities`, чтобы открыть её для редактирования, и сделай её
   активной сценой (ПКМ → *Set Active Scene*).
3. Наведи Scene View на место, где должна стоять станция, и выбери меню
   **GasStation → Создать объекты станции**. Появится объект `GasStationSetup`, в нём:
   - `Station`: деньги, время, резервуары и цены (`StationAuthoring`);
   - `CarSpawner`: откуда приезжают машины, маршрут въезда, голова очереди (`QueueHead`,
     очередь растёт назад по его `-forward`) и маршрут выезда (последняя точка удаляет машину).
     Список машин заполняется автоматически из `Prefabs/Environment/Interactable/Cars` и
     `Models/Interactable/Cars`;
   - `Pump_1`…`Pump_4`: колонки. Игрок взаимодействует с позицией колонки, машина встаёт в
     `StopPoint` и смотрит вдоль его `forward`. Колонки 3 и 4 закрыты, пока не куплено улучшение
     «Новая колонка» (поле `requiredUpgradeLevel`).
4. Расставь точки под окружение, закрой SubScene и нажми Play.
5. Чтобы разбросать мусор, наведи Scene View на нужное место и выбери
   **GasStation → Набросать мусор**. Команда кладёт 30 предметов вокруг центра Scene View.

Колонки можно вешать и прямо на модели колонок (`PumpAuthoring`). Машины едут вдоль своей оси +Z:
если модель повёрнута иначе, заверни её в префаб с поправленным дочерним объектом.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | ходить |
| E / ЛКМ | по приоритету: начать заправку → поменять шины → чинить колонку → убрать туалет → подобрать мусор |
| 1 / 2 / 3 | выбрать топливо (АИ-92 / АИ-95 / ДТ) |
| + / − | поднять / снизить цену выбранного топлива |
| O | заказать 500 л выбранного топлива |
| Tab | улучшения: стр. 1 → стр. 2 → закрыть; цифры 1–6 покупают на открытой странице |
| M | магазин: 1–5 — товар, +/- — цена, O — заказать 20 шт. |
| C | покраска станции: 1–3 — выбрать схему |
| H | персонал: 1–3 — нанять кандидата, 4–9 дважды — уволить |
| J | достижения |
| F | финансы: обзор → банк → конкурент → закрыть. В банке 1 / 2 — кредит, 3 — погасить, 4 — страховка; у конкурента 1 дважды — выкупить |
| B | режим строительства: WASD — камера, колесо — масштаб, 1–8 — объект, Q / E — поворот, ЛКМ — поставить, ПКМ — убрать |
| R | радио: следующая станция / выключить |
| T | скорость игры ×1 / ×2 / ×3 |
| F1 | показать / скрыть подсказки по клавишам |
| Esc | пауза и меню |
| L | переключить язык (русский / английский) |
| F5 / F9 | сохранить / загрузить |
| F10 дважды | новая игра (удаляет сохранение) |

Игра сама загружает сохранение при старте и сохраняется в конце каждого игрового дня
(`Application.persistentDataPath/savegame.json`). Машины на дороге не сохраняются, оплаченные
бензовозы считаются доставленными.

## Ремонт станции и стройка

**Ремонт «до/после».** На заброшенной станции шесть сломанных вещей. Подойди и нажми E, чтобы
отремонтировать за деньги: вид меняется с коротким «поп»-эффектом, растут репутация и поток клиентов.

| Что | Стоит | Уровень | Клиентов | Было → стало |
|---|---|---|---|---|
| Заколоченные окна | $150 | 1 | +3% | доски на витрине → чистые окна |
| Граффити | $120 | 1 | +3% | цветные пятна на стенах → чистые стены |
| Дырявый забор | $250 | 1 | +2% | сетка с дырами → целый забор |
| Старые фонари | $300 | 2 | +4% | `Old_Lamp` → `Lamp` |
| Ржавый автомат | $250 | 2 | +2% | `Vending_machine_Rusted` → `Vending_machine` |
| Покосившаяся вывеска | $400 | 2 | +6% | наклонённая старая вывеска → `Gas_Station_Sign` |

Логика — сущности `Renovation` в SubScene (`RenovationAuthoring`), вид — пары объектов
«Broken/Fixed» с `RenovationVisual` в основной сцене (id совпадают). Задания «Первый ремонт» и
«Новая жизнь», достижение «Как новая». В сценах без точек ремонта эти задания пропускаются.

**Стройка.** Мойка, шиномонтаж (сарай из примитивов с колёсами), мотель, разметка стоянки и
колонки 3–4 появляются только после покупки улучшения. До этого на их месте стройплощадка
(конусы и куча песка), а в момент покупки здание вырастает из земли в оранжевых лесах за 6 секунд.
Компонент — `ConstructionSite` (улучшение, уровень, здание-обёртка, площадка).

## Доставка, ночь и обучение

- **Бензовоз и грузовик с товаром.** Заказ (O, M или завхоз) отправляет машину, когда до доставки
  остаётся 12 секунд: бензовоз заезжает по маршруту клиентов и сливает топливо у колонок, грузовик
  разгружается у магазина (6 секунд), и только после разгрузки топливо или товар поступают.
  Модели собраны из примитивов (`Assets/Prefabs/Vehicles`), их можно заменить своими: вперёд — ось +Z.
  Без `DeliveryTrucksAuthoring` в сцене доставка приходит просто по таймеру.
- **Ночной свет.** С 19:00 до 6:00 (с плавным переходом) включаются фонари вдоль трассы, свет под
  навесом, у вывески и за окнами магазина (`NightLight`). Фонари площадки, вывеска и окна светят
  только после ремонта. При покраске «Неон 80-х» навес и вывеска светят бирюзовым неоном.
- **Обучение.** При первом запуске — четыре страницы вступления (история, как играть, деньги,
  задания); повторить можно из меню «Управление». Оранжевая стрелка ▼ над целью текущего задания
  показывает, куда идти: мусор, изношенная колонка, ждущая машина, сломанная вещь, туалет и т. д.

## Отзывы, финансы, карточки и погода

- **Отзывы.** Каждый клиент ставит 1–5 звёзд: от пяти отнимаются звёзды за долгое ожидание, цену
  выше рыночной и грязь; уехавший без обслуживания ставит одну. У каждой оценки три варианта текста.
- **Финансы (F).** Доход и расходы за сегодня, вчера и неделю, средний рейтинг, последние отзывы и
  график по дням (последние 14 дней: зелёный — доход, красный — расходы). История хранится 30 дней
  и сохраняется.
- **Карточки над машинами.** Над ждущими и заправляющимися машинами — тип клиента, топливо, литры
  и полоса терпения, которая краснеет по мере ожидания (только в HUD на UI Toolkit).
- **Песчаная буря видна:** песочный туман, солнце тускнеет, мимо камеры летит пыль и шумит ветер.

## Банк, счета и конкурент

- **Сложность** выбирается при новой игре. «Спокойная»: счета вдвое меньше, банкротства нет.
  «Обычная»: 7 дней в минусе — банкротство. «Выживание»: счета в 1,5 раза выше, банкротство через
  4 дня.
- **Счета каждую ночь:** электричество (база, свет над колонками, продажи топлива, мойка) и вода
  (мойка, туалет).
- **Каждую неделю** (дни 8, 15, 22…): налог 10% с выручки, платёж по кредиту и взнос за страховку.
- **Кредит:** $5 000 (10%, 4 недели) или $20 000 (18%, 8 недель). Досрочное погашение экономит
  половину оставшихся процентов.
- **Страховка** ($60 в неделю) возмещает 80% украденного топлива и денег, украденных работниками.
- **Банкротство:** с 3-го дня в минусе приходит предупреждение, потом — экран «Банкротство».
- **Конкурент PetroMax** открывается через дорогу на 3-й день. Водители делят себя между станциями
  по цене, репутации, чистоте, услугам и декору. Каждое утро PetroMax отвечает: снижает или
  поднимает цены, устраивает распродажу или рекламу. Его цены видны на табло у дороги и на вкладке
  «Конкурент». С 8-го уровня его можно выкупить за $50 000 — тогда все водители трассы едут к тебе.
- Уровень «Пустыня» строит участок конкурента (сначала пустой, потом заправка) и наше табло цен.

## Режим строительства (B)

Камера отъезжает от игрока, WASD двигает её, колесо меняет масштаб. Цифрами 1–8 выбирается объект,
Q / E поворачивают его на 45°. Призрак показывает место: зелёный — можно поставить, красный — нельзя
(вне участка, на полосе для машин или у здания, слишком близко к другому объекту, не хватает уровня
или денег). ЛКМ ставит объект, ПКМ убирает ближайший и возвращает половину цены. Время при этом идёт.

| Объект | Цена | Уровень | Эффект |
|---|---|---|---|
| Урна | $80 | 1 | в радиусе 6 м клиенты мусорят на 70% меньше |
| Скамейка | $120 | 1 | +4% терпения клиентов (до 5 штук) |
| Клумба | $60 | 1 | +2% трафика (до 10 штук) |
| Фонарь | $200 | 2 | светит ночью; меньше ночных вандалов и воров |
| Указатель | $400 | 2 | +6% трафика (до 3 штук) |
| Подкачка шин | $350 | 3 | иногда +$2 и немного репутации с клиента |
| Автомат с водой | $500 | 3 | иногда +$3 с клиента |
| Камера | $600 | 4 | вор у колонки в радиусе 12 м может попасться сам |

Всего на участке до 60 объектов. Разрешённая площадь и запретные зоны задаются компонентом
`BuildAreaAuthoring` (в сцене видны гизмо: зелёный — участок, красный — зоны). Уровень «Пустыня»
создаёт его сам; зоны расставлены по координатам вслепую, их стоит проверить в редакторе.
Объекты в ECS — это только данные (`PlacedProp`); рисует их `PropPresenter` из примитивов. Старое
улучшение «Декор» пока осталось отдельным.

## Радио, название и декор

- **Радио** (R, выбор и громкость — в настройках): три станции, музыка генерируется при запуске
  (`Mono/Audio/MusicSynth.cs`), без аудиофайлов — «Route 66 FM» (кантри), «Neon Drive» (синтвейв),
  «Desert Chill» (лоу-фай с треском пластинки). Играет и в меню.
- **Название станции** (пауза → «Название станции»): показывается в HUD, над дверью магазина и на
  вывеске у дороги (появляется после ремонта вывески). Сохраняется; по умолчанию «Оазис» / «Oasis».
- **Декор** — улучшение из трёх уровней, объекты появляются сразу после покупки.

## Сборка демо

- **GasStation → Build → Windows (release / development)** собирает игру в `Builds/Windows`
  (перед этим собирается контент Addressables с таблицами локализации). Сцены берутся из
  Build Settings, иначе `Assets/Scenes/Desert.unity`.
- `.github/workflows/unity.yml` (GameCI): EditMode-тесты на каждый push и pull request, сборка
  Windows по тегу `v*` или вручную; артефакт `GasStation-Windows`. Нужны секреты репозитория
  `UNITY_LICENSE`, `UNITY_EMAIL`, `UNITY_PASSWORD` (https://game.ci/docs/github/activation).
- Для Steam дальше понадобятся Steamworks.NET, App ID и перенос достижений в Steamworks.

## Мусор и чистота

- Мусор — сущности с компонентом `Trash`. Его раскладывают в SubScene (`TrashAuthoring`), и его
  бросают клиенты, пока ждут в очереди или на колонке (`TrashSpawnerAuthoring`, шанс в секунду на машину).
- Чистота = 1 − мусор / `dirtyThreshold` (по умолчанию 40). Грязная станция получает до 40% меньше
  клиентов и медленно теряет репутацию, чистая — наоборот.
- Мусор сохраняется: собранный не вернётся после загрузки.

## Персонал

Заправщик, уборщик и механик — теперь не улучшения, а сотрудники (клавиша H). Каждое утро приходят
три кандидата со случайной ролью, навыком (0,6–1,4) и зарплатой, которая растёт с навыком. Найм
стоит одну дневную зарплату, в штате не больше 6 человек. Зарплаты списываются в полночь.

| Роль | Что делает (сила = сумма навыков всех в роли) |
|---|---|
| Заправщик | начинает заправку ждущей машины через 8/сила с |
| Уборщик | убирает кусок мусора раз в 20/сила с и понемногу моет туалет |
| Механик | чинит свободные колонки (1%/с × сила), начинает работу в шиномонтаже |
| Кассир | ускоряет покупки: время в магазине / (1 + 0,5 × сила) |

- Навык растёт на 0,02 за каждый отработанный день (до 1,5).
- Честность скрыта, о ней намекают рекомендации. Нечестный сотрудник иногда ворует из кассы.
- Старые сохранения: купленные уровни «Заправщика», «Уборщика» и «Механика» превращаются в
  сотрудников со средним навыком, их зарплата переходит из постоянных расходов в зарплаты.

## Износ и ремонт

- Колонка изнашивается с каждым литром (полный износ ≈ 2500 л). Сломанная колонка не принимает машин.
- Нажатие E рядом с колонкой, изношенной больше чем на 25%, — шаг ремонта за $40 (+25%);
  шаг, который поднимает её выше 75%, чинит полностью.
- Механики чинят свободные колонки сами.
- В уровне «Пустыня» станция заброшена: колонка 1 едва работает, остальные сломаны.

## Уровень станции

Опыт: клиент +10, мусор +2, задание +50, улучшение +20, ремонт +15, пойманный вор +30,
пройденная проверка +40. Для перехода на следующий уровень нужно 100 × текущий уровень опыта,
максимум — 10. Каждый уровень даёт +5% трафика, открывает улучшения и новых клиентов.

## Клиенты

| Тип | С уровня | Особенности |
|---|---|---|
| Обычный | 1 | — |
| Торопыга | 1 | половина терпения, мало литров, чаевые до 15% |
| Дальнобойщик | 2 | только дизель, бак ×3, терпеливый, медленный |
| Турист | 3 | мусорит втрое больше; в час пик их в 5 раз больше |
| Подозрительный тип | 2 | вор: уедет не заплатив, если игрок не стоит рядом, когда заправка заканчивается; ночью втрое чаще |

## Магазин и мойка

- После оплаты водитель может пойти в магазин (обычный — 35%, дальнобойщик — 60%, турист — 80%).
  Машина всё это время занимает колонку. Водитель — пешеход (`ShopAuthoring.pedestrianPrefab`):
  доходит до двери, 8 секунд внутри, покупает 1–3 товара и возвращается.
- Товары: вода, кофе, снеки, моторное масло, сувениры. Спрос зависит от типа клиента (дальнобойщики
  берут кофе и масло, туристы — сувениры) и от цены относительно обычной. Если полки пусты, покупатель
  уходит ни с чем, а репутация падает.
- Товар заказывается партиями по 20 шт. и приезжает через 30 секунд.
- После улучшения «Автомойка» часть клиентов едет на мойку (одна машина за раз) и платит отдельно.

## Стоянка и туалет

- С 19:00 до 4:00 дальнобойщик после заправки (и магазина) встаёт на свободное место стоянки,
  спит до 5–8 утра и платит $20 за ночь (+25% за второй уровень стоянки).
- Туалетом пользуются 40% покупателей магазина, каждый визит добавляет 8% грязи. Грязный туалет
  снижает чистоту станции (до −40%), а после 70% грязи клиенты возмущаются и репутация падает.
  Убрать туалет — E у двери; уборщики тоже понемногу его моют.

## Шиномонтаж и покраска

- После улучшения «Шиномонтаж» клиенты, которым нужны шины (10%, дальнобойщики — 20%), после колонки
  едут в бокс. Работа начинается, когда игрок нажимает E у бокса (механик начинает сам через 4 с);
  $25 за работу. Кто прождал слишком долго, уезжает без оплаты.
- Покраска (клавиша C): «Облезлая краска» −10% клиентов, «Классика» ±0% ($300), «Пустынный закат»
  +5% ($800, уровень 3), «Неон 80-х» +10% ($1500, уровень 5). `StationPainter` перекрашивает
  здания и колонки через MaterialPropertyBlock. Уровень «Пустыня» начинается с облезлой краской.

## Мотель

- С 18:00 до 3:00 обычные клиенты (25%) и туристы (50%) после заправки снимают свободный чистый
  номер (машина встаёт у номера), спят до 6–9 утра и платят $40 (+25% за уровень), репутация растёт.
- После гостя номер грязный и не сдаётся. Уборка — E у ресепшена (по одному номеру за нажатие),
  уборщики тоже убирают номера.
- В уровне «Пустыня» мотель — вторая модель операторской слева за площадкой, 6 мест у номеров.

## Рынок и события

- Каждое утро рыночные цены сдвигаются на ±8% и тянутся к средней. Оптовая цена — 72% рыночной.
  Если держать цену выше рынка, клиентов становится меньше.
- Раз в игровой час может случиться событие:
  - ночью вандалы разбрасывают 8 кусков мусора;
  - днём приходит санитарная проверка: при чистоте от 70% премия $150, иначе штраф $200;
  - час пик: трафик ×2,5 на 1,5 часа, много туристов;
  - песчаная буря: трафик ×0,4 на 2 часа, по площадке летит мусор.

## Звук

`StationAudio` синтезирует звуки при запуске: касса, гудок недовольного клиента, пистолет, бензовоз,
тревога «топливо закончилось», гул насоса, подбор мусора, выполненное задание. Чтобы заменить их настоящими, добавь `StationAudio` на
объект в сцене и назначь клипы в инспекторе.

## Переход на Unity 6.6

1. Открой проект в Unity 6.6 и согласись на апгрейд.
2. В Package Manager обнови Entities, Entities Graphics, Unity Physics, URP и Input System до версий,
   которые предлагает 6.6. Начиная с Unity 6.4 номера версий DOTS-пакетов совпадают с версией редактора (6.6.x).
3. Пересобери SubScene (закрой и открой её или нажми *Reimport*).

Код уже рассчитан на 6.6:
- нет `IAspect` и `Entities.ForEach`, только `ISystem`, `IJobEntity` и `SystemAPI.Query`;
- нет managed-компонентов, поэтому переход на `CompanionComponent<T>` в 6.6 не затрагивает код;
- нет `FindFirstObjectByType` и перегрузок с `FindObjectsSortMode`, которые устарели при переходе
  с InstanceID на EntityId; используются `FindAnyObjectByType` и `Resources.FindObjectsOfTypeAll`;
- `ComponentLookup.GetRefRWOptional/GetRefROOptional` не используются.

## Меню и настройки

- **Главное меню** открывается при запуске поверх станции (игра на паузе): «Продолжить» /
  «Играть», «Новая игра» (с подтверждением, если есть сохранение), «Настройки», «Управление», «Выход».
- **Пауза** — Esc: продолжить, сохранить, загрузить, настройки, управление, в главное меню, выход.
  Пауза останавливает симуляцию через `Time.timeScale`, клавиши игры в меню не работают.
- **Настройки** (сохраняются в PlayerPrefs):
  - экран: разрешение, режим (полный экран / окно без рамки / окно), V-Sync, ограничение FPS;
  - графика: пресет качества, масштаб рендера URP;
  - звук: общая громкость, звуковые эффекты;
  - интерфейс: язык, размер интерфейса, подсказки по клавишам;
  - игра: скорость ×1–×3, автосохранение в конце дня.
- Код: `Mono/Menu/MenuController.cs`, `SettingsApplier.cs`, данные — `Bridge/GameSettings.cs`,
  стили — `Resources/UI/Menu.uss`. В редакторе разрешение и масштаб рендера не меняются.

## Интерфейс (UI Toolkit)

HUD рисуется через **UI Toolkit**: карточки со скруглёнными углами, полосы репутации, чистоты и
опыта. Ассеты лежат в `Assets/Resources/UI`:
- `GasStationTheme.tss` — тема (импортирует стандартную `unity-theme://default`);
- `Hud.uss` — стили карточек, текста и полос.

Panel Settings создаются при запуске кодом (`Mono/Hud/ToolkitHudView.cs`), дерево элементов тоже
строится в коде. Шрифт — встроенный `LegacyRuntime.ttf`: он берёт недостающие символы из системных
шрифтов, поэтому кириллица отображается. Если ассетов в `Resources/UI` нет, включается прежний HUD
на uGUI (`UguiHudView`). Логика HUD одна: `StationHud` собирает тексты и передаёт их в `IHudView`.

## Достижения

(версия сохранения 9).

## Локализация (русский / английский)

Тексты интерфейса идут через **Unity Localization** (пакет `com.unity.localization`, таблица строк
`GasStation`, локали `en` и `ru`).

1. После открытия проекта выбери **GasStation → Localization → Setup (English, Russian)**. Команда
   создаёт Localization Settings, обе локали и коллекцию таблиц строк, заполняя её из
   `Localization/LocTable.cs`. Команду можно запускать повторно: она добавит новые ключи.
2. Переводы можно править в *Window → Asset Management → Localization Tables*.
3. В игре язык переключается клавишей **L**, выбор запоминается. При первом запуске язык берётся из
   языка системы.

Пока Localization Settings не настроены, игра показывает те же строки из `LocTable`, так что
текст есть всегда. Новые строки добавляются в `LocTable` (ключ → русский и английский), а в коде
используются через `Loc.T("key")` или `Loc.F("key", args)`.

## Структура кода

```
Assets/Scripts/                 GasStation.Runtime.asmdef
  Components/  Movement, Player, Cars, Station, Traffic   — ECS-данные
  Authoring/   Movement, Player, Station, Traffic         — MonoBehaviour + Baker
  Systems/     Input, Player, Camera, Time, Traffic, Station, Bridge
  Logic/       StationMath, CarRoutes — чистые формулы, покрыты тестами
  Bridge/      HudModel (ECS → UI), StationCommands (UI → ECS), GameTexts
  Localization/ LocTable (строки RU/EN) и Loc (обёртка над Unity Localization)
  Save/        SaveData (JSON) и SaveService
  Mono/        HUD (Hud/: StationHud + UI Toolkit / uGUI вид), звук, смена дня и ночи, покраска, камера, Zenject-инсталлер
  Input/       сгенерированный PlayerInputAction
  Editor/      генератор уровня «Пустыня», меню станции и мусора (GasStation.Editor.asmdef)
Assets/Tests/EditMode/          EditMode-тесты (Window → General → Test Runner)
```

Цикл одной машины: `Arriving → Queued → DrivingToPump → WaitingForService → Fueling → Leaving`.

Игровые события (оплата, ушедший клиент, закончилось топливо, бензовоз и т. д.) Burst-системы пишут в
буфер `StationEvent` на сущности станции. `HudBridgeSystem` раз в кадр забирает их для HUD и звука.
